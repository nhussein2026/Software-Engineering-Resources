# 📚 Software Engineering Knowledge Hub

Welcome to my curated collection of Software Engineering resources! This repository serves as a centralized hub for books, learning roadmaps, and academic papers covering various domains in computer science and software engineering.

## 📂 Repository Structure

The library is organized into three main categories:

### 📖 Books
Comprehensive guides and textbooks across core tech domains.
- **AI**: Deep Learning
- **Algorithms**: Introduction to Algorithms, Object-Oriented Technology
- **Cyber Security**: Security fundamentals
- **Software Development**: Clean Code, The Pragmatic Programmer
- **Web Development**: Web applications architecture

### 🗺️ Learning Plans
Curated roadmaps and skill trees to guide learning paths for various roles:
- **Artificial Intelligence**: AI Agents, AI Engineering, Data Science
- **Cloud & DevOps**: AWS, Cloudflare, Kubernetes, Docker, Terraform
- **Data**: Data Analytics
- **Software Engineering**: Computer Science, System Design, Software Design Architecture
- **Security**: AI Red Teaming

### 📄 Papers
Academic papers and technical reports:
- **AI**: AI-Driven Virtual Teachers, LLM research.
- **Dataset Bias**: Mitigation strategies and bias analysis.
- **Datasets**: Sample datasets for performance analysis.
- **Education**: Impact of conflict on education and academic studies.
- **Writing Resources**: Guides on writing professional research papers.
- **General**: Research notes and drafts.

## 🚀 Getting Started

Simply browse through the folders to find the resources you need. All files are categorized by their primary domain. Whether you're looking for a deep dive into Algorithms or a roadmap for becoming a Cloud Engineer, you'll find it well-organized here.
